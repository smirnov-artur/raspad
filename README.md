# РАСПАД / DECAY

Три́ллер о материи в браузере: структура собирается из пыли, горит там, где вы её жжёте
курсором, рушится твёрдыми кусками, догорает и взмывает пеплом — а пепел собирает
следующую структуру. Каждый цикл — новая архитектура.

**Демо: RU — https://smirnov-artur.github.io/raspad/ · EN — https://smirnov-artur.github.io/raspad/en/**

```
курсор — жжёт бетон        колесо / щипок — время 0.05–1×
двойной клик — акт вперёд  наклон телефона — вектор гравитации
8 секунд без ввода — автопилот-режиссёр
```

## Что здесь необычного

- **262 144 частицы, вся физика на GPU.** Ping-pong FBO с MRT, свой микро-фреймворк
  (`js/sim.js`): `GPUComputationRenderer` не умеет несколько выходов на пасс, а нам нужны
  позиция+фаза и скорость+тепло за один проход.
- **Твёрдотельная физика обломков целиком в шейдере.** ~800–1000 Вороной-кластеров:
  интеграция кватернионов, контакт с полом по восьми предвычисленным крайним точкам,
  импульс с торком, демпфирование, засыпание. Ни грамма CPU-физики, ноль трафика
  CPU→GPU в кадре.
- **Разрушение причинно.** У каждого куска своя зона на фасаде (UV-атлас 2×2, четыре
  стороны раздельно). Огонь — поле реакции-диффузии Грея–Скотта 512², затухающее без
  подпитки курсором. Кусок отваливается, когда прогрета его зона либо когда под ним
  рухнула опора — граф опор строится при генерации структуры.
- **Растворение.** Раскалённый воксель съёживается: материал выгорает в решето и лишь
  потом уходит пеплом.
- **Архитектура процедурная.** Три семейства: решётчатая башня (ноги по гиперболе,
  X-раскосы, платформы, шпиль), собор с контрфорсами и куполом, небоскрёб с
  перекрытиями этажей и ядром жёсткости. Обрушение вскрывает внутренности.
- **Звук синтезирован.** Ни одного аудиофайла: пентатонические пинги защёлкивания
  вокселей на сборке, треск фронта горения, гул обрушения через `ConvolverNode` с
  процедурным импульсом, саб-дрон.
- **Драматургию ведёт материя.** Акт обрушения наступает, когда реально сорвалось
  больше половины кластеров, а не по таймеру.

Ноль внешних ассетов: ни моделей, ни текстур, ни шрифтовых файлов, ни звуков.
Ноль зависимостей кроме three.js, ноль сборки — `view-source` показывает всё как есть.

## Запуск

Нужен http-сервер (ES-модули не грузятся с `file://`):

```
python -m http.server 8080
```

Тесты генератора геометрии:

```
node --input-type=module -e "import('./js/test-geometry.js')"
```

## Устройство

| файл | что делает |
|---|---|
| `js/sim.js` | ping-pong рендертаргеты с MRT, исполнитель фуллскрин-пассов |
| `js/shaders.js` | все GLSL строками: кластеры, частицы, огонь, кубы, пепел, пост |
| `js/geometry.js` | процедурные структуры, вокселизация, Вороной-кластеры, граф опор, Morton |
| `js/audio.js` | WebAudio-синтез без файлов |
| `js/main.js` | акты, камера, ввод, рендер-пайплайн |

Отладочные флаги: `?tele` — телеметрия в заголовке вкладки, `?act=N` — прыжок в акт,
`?nw` — без вступительного слова, `?seed=N` — фиксированная структура, `?n=128|256|512` —
тир качества. Клавиша `` ` `` открывает оверлей со статистикой.
